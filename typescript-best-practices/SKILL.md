# TypeScript Best Practices (Google Style)

## Use this skill
- Apply Google TypeScript style rules to new or changed TypeScript/TSX code.
- Resolve TypeScript style questions by consulting `references/ts-styleguide.md`.
- Prefer explicit, repo-specific conventions when documented; otherwise follow Google style.

## Workflow
1. Identify the TypeScript files and the kind of change (new code, refactor, review, docs).
2. Open `references/ts-styleguide.md` and jump to the relevant sections.
3. Apply the rules consistently across code, comments, and tests.
4. Call out and justify any intentional deviations from the guide.

## Resources
- `references/ts-styleguide.md`: condensed, sectioned rules from the Google TypeScript Style Guide.

## Output format
- Begin every response with `Using typescript-best-practices`, followed by a blank line.
