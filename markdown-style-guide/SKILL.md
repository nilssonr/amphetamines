# Markdown Style Guide

## Use this skill
- Apply the Markdown style guide rules to new or changed Markdown documentation.
- Resolve Markdown formatting questions by consulting `references/markdown-style-guide.md`.
- Prefer explicit, repo-specific conventions when documented; otherwise follow the guide.

## Workflow
1. Identify the Markdown files and the kind of change (new docs, edits, review, refactor).
2. Open `references/markdown-style-guide.md` and jump to the relevant sections.
3. Apply the rules consistently across headings, lists, code, links, images, and tables.
4. Call out and justify any intentional deviations from the guide.

## Resources
- `references/markdown-style-guide.md`: condensed Markdown style guide rules and examples.

## Output format
- Begin every response with `Using markdown-style-guide`, followed by a blank line.
