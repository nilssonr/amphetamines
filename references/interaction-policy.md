# Interaction Policy

## Defaults
- Prefer repo evidence over user preferences when the repo already dictates a choice.
- Default responses are concise: 1–4 bullets or 2–5 short sentences.
- Do not use multi-section outputs unless explicitly requested.

## Questions
- Ask at most one blocking question at a time.
- Only ask a question if the repo does not answer it or evidence conflicts.
- If repo evidence is clear, proceed and state the assumption.

## Preflight scan
- Before asking questions, scan README/docs/config/templates/scripts for relevant conventions.
- Cite the paths you relied on.
